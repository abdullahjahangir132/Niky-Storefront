==============================================================
SECTION 3 — TECH STACK
==============================================================

RECOMMENDED: MERN Stack

Frontend (client/):
- React.js 18 with React Router v6
- Tailwind CSS for styling
- Framer Motion for animations
- Redux Toolkit for state (cart, wishlist, auth)
- Axios for API calls
- React Hot Toast for notifications
- Swiper.js for sliders/carousels
- React Icons for all icons

Backend (server/):
- Node.js + Express.js
- MongoDB + Mongoose
- JWT for authentication
- Bcrypt for password hashing
- Multer + Cloudinary for image uploads
- Nodemailer for order confirmation emails
- Express Validator for input validation
- CORS configured for frontend URL

SECTION 6 — EXTRA REQUIREMENTS
==============================================================

Performance:
- Lazy load images (loading="lazy")
- Code splitting with React.lazy()
- Product images compressed before upload
- API responses paginated

Security:
- JWT tokens expire in 7 days
- Admin routes protected by middleware
- Passwords hashed with bcrypt (salt rounds: 12)
- Input sanitization on all forms
- Rate limiting on auth routes

UX Requirements:
- Loading skeleton screens (not spinners) while data fetches
- Empty states with helpful messages and CTAs
- Form validation with inline error messages (red text below input)
- Success toast: bottom-right, green, auto-dismiss 3s
- Error toast: bottom-right, red, auto-dismiss 5s
- Confirm dialogs before any delete action
- Smooth page transitions

Mobile Experience:
- Touch-friendly: all buttons min 44px height
- Swipeable product image gallery on mobile
- Bottom navigation bar on mobile (Home, Shop, Cart, Account)
- Cart sidebar slides in from right on desktop, 
  full screen on mobile
